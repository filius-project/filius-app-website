## Ping échoue

Vérifiez le câble, l’unicité des adresses, le préfixe réseau, les routes entre réseaux différents, le pare-feu et le démarrage de la simulation.

## Impossible d’ouvrir un projet

- Confirmez qu’il s’agit d’un fichier `.fls`.
- Travaillez sur une copie inchangée.
- Notez le message d’erreur exact.
- N’écrasez pas plusieurs fois une archive potentiellement endommagée.

## Application absente

Vérifiez son installation dans le gestionnaire de logiciels. Certaines applications nécessitent aussi une configuration réseau valide ou un serveur actif.

## Assistance

Écrivez à [support@filius.app](mailto:support@filius.app) avec les versions, le modèle d’iPad, les étapes, le résultat attendu et le résultat observé. Partagez uniquement des fichiers nettoyés et sur demande.
