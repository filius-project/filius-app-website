## Ping fails

Check cable state, unique addresses, network prefix, router and routes for separate networks, firewall rules, and whether simulation is running.

## A project will not open

- Confirm the file is an `.fls` project.
- Work from an unchanged copy.
- Record the exact error message.
- Do not repeatedly overwrite a possibly damaged archive.

## An application is missing

Open the virtual device’s software manager and verify installation. Some applications also require valid network configuration or a running server.

## Ask for help

Email [support@filius.app](mailto:support@filius.app) with the app version, iPadOS version, device model, reproduction steps, expected result, and actual result. Share only redacted files and only after request.
