## Requirements

- iPad running **iPadOS 17 or later**
- A Filius on iPad build compatible with the device
- No physical lab network is required for local simulations

The final support statement must match the published App Store build.

## Projects

Filius on iPad works with `.fls` FILIUS project files. You can create, open, edit, save, and share projects through normal iPad file workflows.

:::tip
Use synthetic names, addresses, and content in classroom projects so files can be shared without personal data.
:::

## Interface

The main areas are the file and mode toolbar, hardware palette, topology canvas, adaptive inspector, and runtime workspaces for virtual devices and diagnostics. Layout adapts to portrait, landscape, and Split View.
