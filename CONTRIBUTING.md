# Contributing

The repository is in pre-release preparation and does not yet grant a public contribution license.

Before public contributions open, the project must approve its root license, contributor terms, asset provenance, issue policy, and security-reporting channel.

For approved internal work:

1. create a focused branch;
2. run `npm run validate`;
3. run Playwright tests for user-interface changes;
4. update all three locales when changing shared product claims; and
5. include screenshots for visual changes at desktop and iPad widths.
